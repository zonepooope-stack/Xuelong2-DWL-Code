# Code Availability

Custom MATLAB code used to collocate the processed shipborne Doppler-lidar observations with ERA5 and to generate the code-based panels in Figures 1 and 3-9 is available at https://github.com/zonepooope-stack/Xuelong2-DWL-Code. The repository also contains the derived vessel residence-time table used for ERA5 grid-cell weighting. The code was developed and checked using MATLAB R2024b with Mapping Toolbox and Statistics and Machine Learning Toolbox. Figure 2 and Figure 3c are conceptual diagrams and were not generated by the analysis code.
